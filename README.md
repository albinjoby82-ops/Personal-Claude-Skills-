# Personal Claude Skills

My Claude skills, one folder each. Backup and source of truth. To install a skill, paste its `SKILL.md` into a Claude skill proposal and save.

## Find a skill

1. Scan the index below (grouped by category).
2. Or search: `grep -ril "keyword" skills/` or use GitHub's search box.
3. Skill names are `topic-or-verb-noun` in lowercase kebab-case, so the folder list is readable too.

## Adding a skill

Follow [CLAUDE.md](CLAUDE.md). Short version:

1. Make `skills/<name>/SKILL.md`. The folder name must equal `name:` in the frontmatter.
2. Frontmatter: `name`, `description`, `category`, `tags`.
3. Run `python3 scripts/build_index.py`, then commit and push.
